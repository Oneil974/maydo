Premiers pas

Faut-il créer un compte ?

Non. MayDo fonctionne sans compte et sans inscription. Vos données restent sur votre iPhone, et sur votre Mac si vous utilisez MayDo Server.

Quel modèle d'IA choisir au premier lancement ?

Le démarrage express propose un modèle local de Liquid AI adapté à l'iPhone. Il est téléchargé une seule fois depuis Hugging Face (de quelques centaines de Mo à quelques Go), puis fonctionne hors ligne. Sur les appareils compatibles, Apple Intelligence est aussi disponible. Vous pouvez changer de moteur à tout moment avec le sélecteur en haut de l'accueil.

L'app a besoin de beaucoup d'espace ou de mémoire ?

Un modèle local occupe de l'espace de stockage et, pendant une réponse, de la mémoire vive. La pastille de ressources en haut de l'accueil indique la mémoire utilisée et la température de l'appareil. Touchez-la puis « Éjecter » pour libérer la mémoire d'un modèle.

À quoi sert le @ dans le champ de demande ?

Tapez @ pour choisir un outil précis (recherche web, mémoire, tâches, document…). MayDo est alors obligé de l'utiliser avant de répondre, et la réponse s'affiche une fois l'outil exécuté.

Réponses et modèles d'IA

« Le contexte local est trop petit »

Le contexte est la mémoire de travail du modèle. Augmentez-le dans Réglages › Modèle (8 192 jetons ou plus pour la recherche web), ou réduisez la longueur des réponses. Le mode Économie d'énergie de l'iPhone limite le contexte à 2 048 jetons, quel que soit le réglage : désactivez-le ou rechargez l'iPhone.

Une réponse s'interrompt ou l'app ralentit

Les gros modèles demandent beaucoup de mémoire. Fermez les autres apps, choisissez un modèle plus léger ou éjectez les modèles inutilisés depuis la pastille de ressources. Une réponse interrompue peut être reprise avec « Reprendre ».

Que montre le bouton ⓘ sous une réponse ?

Les statistiques de génération : vitesse en jetons par seconde, jetons produits, durée, et le détail de chaque appel au modèle (iPhone, API ou MayDo Server). Le signe ≈ indique une estimation quand le fournisseur ne communique pas les jetons.

Utiliser un modèle dans le cloud

Dans Réglages › Moteur, choisissez un fournisseur (OpenAI, Anthropic, Mistral, Google Gemini, Groq, OpenRouter…) et saisissez votre propre clé API. La clé est conservée dans le trousseau de l'iPhone. Vos demandes partent alors chez ce fournisseur, selon ses conditions. Les données personnelles (agenda, tâches, santé…) ne lui sont envoyées que si vous l'autorisez dans Mémoire › Autorisations.

La recherche web ne trouve rien ou se trompe de sujet

Vérifiez la connexion et le moteur choisi dans Réglages › Recherche web (DuckDuckGo, Brave, Mojeek, Wikipédia ou votre instance SearXNG). Pour résumer une page précise, collez son adresse : MayDo la lit directement.

Mémoire et données

Que contient l'onglet Mémoire ?

Vos contenus (notes, documents, dossiers interrogeables, tâches, productions des apps, conversations), ce que MayDo a retenu de vous, et les autorisations. Une seule recherche parcourt l'ensemble.

MayDo retient-il des choses sans me le dire ?

Non. Quand l'assistant propose de retenir une information, elle arrive dans Mémoire › Retenu › À confirmer. Vous pouvez la valider ou l'oublier. Désactivez « Proposer de nouveaux souvenirs » dans Autorisations pour ne plus recevoir de propositions.

Empêcher l'assistant de lire certaines données

Mémoire › Autorisations : un interrupteur par source (tâches et notes, documents, agenda, rappels, contacts, santé, position, recherche web, musique, photos). Une source désactivée n'est plus lue ni par l'assistant, ni par la recherche, ni par les agents. Vous pouvez aussi retirer un accès dans Réglages iOS › Confidentialité.

Supprimer mes données

Une conversation, une note ou un souvenir se supprime depuis l'app. Pour tout effacer, supprimez l'app de l'iPhone : toutes ses données locales disparaissent avec elle. Si vous utilisez MayDo Server, révoquez l'iPhone dans l'onglet Appairage du Mac pour effacer ses données côté serveur.

Sauvegarde et changement d'iPhone

Les données de MayDo font partie de la sauvegarde de l'iPhone (iCloud ou ordinateur) selon vos réglages iOS. Les modèles d'IA téléchargés ne sont pas sauvegardés : ils se téléchargent à nouveau.

MayDo Server (Mac)

À quoi sert MayDo Server ?

C'est une app Mac facultative. Elle fait tourner vos agents et vos missions programmées sur le Mac, même quand l'iPhone est éteint, et peut fournir un moteur d'IA plus puissant à l'iPhone.

Associer l'iPhone au Mac

Sur le Mac, ouvrez MayDo Server › Appairage pour afficher le QR code. Sur l'iPhone : Réglages › MayDo Server › Scanner. Autorisez MayDo Server à accéder au réseau local quand macOS le demande (Réglages Système › Confidentialité et sécurité › Réseau local).

« MayDo Server injoignable »

Vérifiez que le Mac est allumé, réveillé, que MayDo Server est ouvert et que les deux appareils sont sur le même réseau (ou sur votre VPN). Si l'adresse du Mac a changé, l'iPhone le retrouve automatiquement sur le réseau local.

La connexion est-elle sécurisée ?

Oui. L'iPhone et le Mac échangent des clés au moment de l'appairage ; chaque échange est ensuite chiffré et authentifié. Aucun serveur intermédiaire ni service cloud de MayDo n'intervient.

Frequently asked questions

Do I need an account?

No. MayDo works without any account. Your data stays on your iPhone, and on your Mac if you use MayDo Server.

Which AI model should I use?

Quick start offers an on-device Liquid AI model, downloaded once from Hugging Face and then usable offline. Apple Intelligence is available on compatible devices. You may also connect a cloud provider with your own API key; requests are then sent to that provider under its terms.

“The local context is too small”

Increase the context in Settings › Model (8,192 tokens or more for web search). iPhone Low Power Mode limits the context to 2,048 tokens regardless of the setting.

Control what the assistant can read

Memory › Permissions has one switch per data source. A disabled source is no longer read by the assistant, search or agents. New memories always wait for your confirmation.

Delete my data

Delete items in the app, or delete the app to erase all its local data. With MayDo Server, revoke the iPhone in the Mac's Pairing tab to erase its server-side data.

MayDo Server cannot be reached

Make sure the Mac is awake, MayDo Server is open, both devices are on the same network (or VPN) and local network access is allowed in macOS privacy settings.
